JARVIS 0.1.6です。

- macOSのJARVISアプリメニューから「アップデートを確認…」を選べるようになりました。
- 起動時に新しいバージョンが見つかった場合、確認ダイアログから更新を開始するか後で行うかを選べます。
- 音声セッション開始の各段階にタイムアウトを設け、マイク許可やWebRTC接続の失敗時に「接続中」のまま残らないようにしました。
- タイムアウトや中断の後に遅れて取得されたマイクも確実に解放します。

- 起動時に更新を確認し、設定画面から署名付きアップデートを適用できます。
- 会話中は更新せず、更新後は「再起動する」で新しいバージョンに切り替えます。
- 初回のみ、ご利用のMacに合うアーカイブを展開してJARVIS.appをインストールしてください。
  Apple Siliconは `darwin-aarch64`、Intel Macは `darwin-x86_64` を選択します。

配布アプリはApple Developer IDで署名し、Appleの公証とstapleを完了したものだけを公開します。Tauri updater署名も引き続き更新ファイルに付与します。
