JARVIS 0.1.10です。

- macOS 26以降で大きなネイティブ実行ファイルの署名を正しく読み込めるよう、4KBページのコード署名で配布します。

- macOS版に、JARVISの画面内で使える仮想ブラウザを追加しました。
- 仮想ブラウザは複数開くことができ、移動、サイズ変更、最小化、終了ができます。透明度は設定画面からまとめて変更できます。
- 音声でページを開き、表示内容を確認し、リンク移動、入力、ボタン操作、スクロール、戻る・進むを行えます。
- 入力やページ上のボタン操作などは、現在の依頼で明示されていない場合にJARVIS上で1回限りの確認を表示します。
- 設定画面からChromeプロファイルを選び、CookieをJARVISへまとめて取り込めます。対象ドメインを指定すれば、そのサイトだけに絞り込めます。Cookie値と復号鍵は画面、AI、Tachyon、ログへ送信しません。
- Chromeプロファイルへの初回アクセス時は用途を明記したmacOSの許可確認を表示します。拒否済みなどで読み取れない場合は、フルディスクアクセスを案内し、macOSの設定を直接開いて再確認できます。Chromeのプロファイル名とアカウント、前回使用したプロファイルを表示して選び間違いを防ぎます。Cookie復号のキーチェーン確認を拒否・中断した場合も、次に必要な操作を表示します。
- 設定画面から対象サイトのCookieと、表示中サイトのローカルデータを削除できます。
- 正式署名版のmacOSアプリでマイクを利用できるように、音声入力の権限設定を追加しました。初回起動時に確認が表示されたら「許可」を選んでください。

アプリ内ブラウザとChrome Cookie取込はmacOS 14以降が対象です。Chrome固有または端末に結び付いたセッションでは、Cookie取込後も再ログインが必要な場合があります。

アップデートに対応した既存版では、起動時またはJARVISアプリメニューの「アップデートを確認…」から更新できます。
会話中は更新せず、更新後は「再起動する」で新しいバージョンに切り替えてください。

- 初回のみ、ご利用のMacに合うアーカイブを展開してJARVIS.appをインストールしてください。
  Apple Siliconは `darwin-aarch64`、Intel Macは `darwin-x86_64` を選択します。

配布アプリはApple Developer IDで署名し、Appleの公証とstapleを完了したものだけを公開します。Tauri updater署名も引き続き更新ファイルに付与します。
